Powered by Ansible automation and Podman 5+ Quadlets, it wires together seven hardened services — from SMTP ingress to webmail — with zero root dependencies and absolute storage sovereignty.

## How Deployment Works

<Steps>
  <Step title="Prepare your host">
    Install Podman 5+ and Ansible 9+ on each target node. SongketMail handles all kernel tuning and user provisioning automatically.
  </Step>
  <Step title="Configure inventory and variables">
    Add your server hostnames to `inventory/hosts.ini` and review `group_vars/all.yml` to set your cluster prefix, image tags, and storage paths.
  </Step>
  <Step title="Run the Ansible playbook">
    Execute `ansible-playbook -i inventory/hosts.ini site.yml`. The playbook prepares the OS, deploys all Quadlet unit files, and starts every service.
  </Step>
  <Step title="Verify and access">
    Check service status with `systemctl --user status`, then open the Roundcube webmail interface at your configured domain.
  </Step>
</Steps>

<Note>
  SongketMail runs all mail services as the unprivileged `songketmail` user (UID/GID 2001). Root access is only used for one-time host tuning tasks during initial setup.
</Note>
