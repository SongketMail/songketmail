# Welcome to SongketMail

SongketMail is an enterprise-grade email server fabric orchestrated via Ansible and Podman 5+ using systemd Quadlets.

## Features

- **Decoupled Architecture**: Rootless container services for Proxy, MTA, IMAP, DB, S3 Storage, Webmail, and Spam Filtering.
- **Persistence Trinity**: Cluster-prefixed networks, systemd Quadlets, and node-isolated host storage.
- **S3 Object Storage**: Dovecot Obox driver with RustFS backend and compressed message blocks.
