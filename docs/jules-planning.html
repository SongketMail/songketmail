📋 Google Jules End-to-End Operational Plan

This comprehensive operational roadmap outlines the step-by-step procedures to bootstrap a bare-metal minimal Linux server, automate the deployment of the secure SongketMail Email Server Fabric via FQCN-compliant Ansible Playbooks, and integrate DockPod for unprivileged container control and AI Model Context Protocol (MCP) diagnostics.

🚀 Phase 1 Goal

Deploy a fully decoupled, unprivileged 7-service container mesh (BunkerWeb, Postfix, Dovecot, PostgreSQL, MinIO, Roundcube, Rspamd) starting from a minimum Linux OS, configured recursively with storage sovereignty (keep-id) and standard-compliant Ansible.

Step 1.1 Host OS Preparation & Tuning (Rootful)

Configure the underlying OS host environment with necessary kernel parameter optimizations and the non-privileged user account:

  • # Install podman & ansible
  • apt update && apt install ansible podman -y
  • # Unprivileged port binds start at 25
  • sysctl -w net.ipv4.ip_unprivileged_port_start=25
  • # Add user & group 2001:2001
  • useradd -u 2001 -g 2001 -m -s /bin/bash songketmail
  • # Enable systemd user session lingering
  • loginctl enable-linger songketmail

Step 1.2 Sovereign Storage Path Creation (UID 2001)

Construct physical host volumes under /var/srv/songketmail with strict ownership mapped directly to the unprivileged owner namespace:

  • mkdir -p /var/srv/songketmail
  • # Create 14 isolated subdirectories
  • # (postfix, dovecot, postgres, etc.)
  • chmod 0700 /var/srv/songketmail
  • chown -R 2001:2001 /var/srv/songketmail

Step 1.3 Ansible Playbook Orchestration

Write standard FQCN-compliant variables and templates. Execute the playbook cleanly via local or remote Ansible orchestration:

ansible-playbook -i inventory/hosts.ini site.yml

This playbook automates host preparations as root, then switches to unprivileged context to deploy Quadlets seamlessly.

Step 1.4 Quadlet Generation & Activation

Generate native user-level systemd service files by reloading the unprivileged session manager daemon:

  • export XDG_RUNTIME_DIR="/run/user/2001"
  • export DBUS_SESSION_BUS_ADDRESS="unix:path=/run/user/2001/bus"
  • systemctl --user daemon-reload
  • systemctl --user enable --now songketmail_pod-pod.service
  • systemctl --user enable --now songketmail_proxy.service

Step 1.5 Verify Mail Web Application

Verify that services are running and accessible. Ports 25, 80, 443, 587, and 993 will be bound securely on the host by BunkerWeb:

ss -tulnp | grep -E "25|80|443|587|993"

Access the Roundcube client through your web browser at https://mail.songketmail.internal/. The email web is now fully ready!

📊 Phase 2 Goal

Provision DockPod as a secure, local, unprivileged management portal and Model Context Protocol (MCP) server, allowing AI clients to stream live container logs and inspect cluster performance safely.

Step 2.1 Enable Podman Rootless Socket

Enable and start the user-level Podman API socket within the unprivileged songketmail user session context:

  • systemctl --user enable --now podman.socket
  • ls -la /run/user/2001/podman/podman.sock

Step 2.2 Deploy DockPod Systemd Service

Deploy the DockPod binary to ~/.local/bin/dockpod and write the unprivileged service unit ~/.config/systemd/user/dockpod.service binding strictly to localhost loopback addresses:

systemctl --user daemon-reload && systemctl --user enable --now dockpod.service

Step 2.3 Route Traffic through BunkerWeb Ingress

Create secure proxy routing configurations inside the BunkerWeb proxy layer to map SSL traffic for the panel.songketmail.local and mcp.songketmail.local (SSE disabled buffer) domains.

Step 2.4 API Token Generation & Hardening

Secure administrative access to DockPod, register the primary admin user with high entropy credentials, and generate a secure, Bcrypt-hashed MCP access token starting with dp_mcp_ from Settings.

Step 2.5 Connect External AI Clients (Google Jules)

Add the secure remote SSE server definition inside the client's configuration file to enable real-time container log analysis and automated server monitoring.
