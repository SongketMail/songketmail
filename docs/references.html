📚 Project References & Resources

Master Compiled Resource Log

To maintain absolute reproducibility, architectural clarity, and alignment with enterprise best practices, this master document contains the complete list of verified URLs, documentation pages, Wikipedia links, and internal resources utilized to build and deploy the unprivileged SongketMail email server fabric.

🐳 1. Container Engines & Orchestration

SongketMail services are containerized natively on rootless Podman 5+ and systemd Quadlets.

  • Podman Official Site: https://podman.io/
  • Podman Documentation: https://docs.podman.io/
  • Podman Quadlet Unit Specs: Quadlet Specifications Manual
  • Systemd User Manager: Systemd User Manager Guide
  • Podman Wikipedia Page: Wikipedia: Podman

🤖 2. Automation Framework

All deployment configuration, privilege separation, and environment preparation run via Ansible playbooks.

  • Ansible Official Site: https://www.ansible.com/
  • Ansible Documentation: https://docs.ansible.com/
  • Ansible FQCN Standards: Using FQCN Collections
  • Ansible Wikipedia Page: Wikipedia: Ansible

✉️ 3. Mail Servers & Transport Protocols

Decoupled MTA (Postfix) and MDA (Dovecot) are interconnected over LMTP inside the isolated bridge network.

  • Postfix Official Site: https://www.postfix.org/
  • Postfix PostgreSQL Guide: Postfix PGSQL Lookup Maps
  • Postfix Wikipedia Page: Wikipedia: Postfix
  • Dovecot Official Site: https://www.dovecot.org/
  • Dovecot Obox/S3 Reference: Dovecot Object Storage Plugin
  • Dovecot Wikipedia Page: Wikipedia: Dovecot

🌐 4. Web Proxy & Protocol Preservation

Nginx handles front-end webmail proxying and TCP mail connection load balancing with client IP preservation.

  • Nginx Official Site: https://nginx.org/
  • Nginx Mail Core Module: ngx_mail_core_module Documentation
  • Nginx PROXY Protocol: Client IP Preservation via PROXY Protocol
  • Nginx Wikipedia Page: Wikipedia: Nginx

🛡️ 5. Spam Mitigation & Content Policies

Rspamd applies filtering, graylisting, and milter integration dynamically.

  • Rspamd Official Site: https://rspamd.com/
  • Rspamd Documentation: Rspamd Quickstart Guide
  • Rspamd Wikipedia Page: Wikipedia: Rspamd

🗄️ 6. Relational Database & Account Virtualization

PostgreSQL is utilized to map virtual domains, user accounts, and alias records securely.

  • PostgreSQL Official Site: https://www.postgresql.org/
  • Postgres Docker Hub: PostgreSQL Docker Image
  • PostgreSQL Wikipedia Page: Wikipedia: PostgreSQL

🪣 7. S3-Compatible Object Storage Engines

We evaluated and compared multiple scalable object storage backends before adopting MinIO.

  • MinIO Official Site: https://min.io/
  • MinIO Container Guide: MinIO Podman/Docker Deployment Manual
  • MinIO Wikipedia Page: Wikipedia: MinIO
  • SeaweedFS GitHub: SeaweedFS Source Code
  • Garage S3: Garage S3 Project
  • Ceph Official Site: https://ceph.io/
  • Ceph Wikipedia Page: Wikipedia: Ceph

📧 8. Open-Source Webmail Clients

Roundcube was chosen as the baseline for user interface settings persistence and mail access.

  • Roundcube Official Site: https://roundcube.net/
  • Roundcube Docker Hub: Roundcube Docker Container
  • Roundcube Wikipedia Page: Wikipedia: Roundcube
  • SnappyMail: SnappyMail Project Home
  • Nextcloud Mail: Nextcloud Suite

🛡️ 9. Security Hardening, Compliance & Audits

Compliance scanning and packages integrity verification are modeled after the ASIMP deployment methodology.

  • Lynis Auditing Tool: https://cisofy.com/lynis/
  • Lynis Wikipedia Page: Wikipedia: Lynis
  • OpenSCAP Compliance: https://www.open-scap.org/
  • OpenSCAP Wikipedia Page: Wikipedia: OpenSCAP
  • Debsums Package Checker: Debsums Man Pages

The developer workflow is assisted by Gemini and Jules, leveraging structured frontmatter (OKF v0.1) and GitBook/GitHub Pages rendering.

  • GitHub Pages: https://pages.github.com/
